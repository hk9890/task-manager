# taskmgr user guide

Eight pages, in reading order. Start at [Getting started](getting-started.md).

`taskmgr` is a task tracker made of files. Every issue is one Markdown file under a
`.tasks/` directory you keep next to your code, so your tasks branch, diff, review and
merge the way the rest of the repository does. There is no database, no server, and
nothing to sign in to.

Everything here is also reachable from the terminal: `taskmgr guide` prints a short how-to,
`taskmgr <command> --help` explains one command, and `taskmgr commands` prints the whole
catalog for a script to read.
