Every issue but a doc carries four sections, and a write without them is refused:

  ## Context   ## Problem   ## Recommended action   ## Acceptance criteria

An epic carries Context, Outcome, Success criteria instead. Acceptance criteria
must hold at least one "- [ ]" item, each runnable by someone who was not there.

Read taskmgr guide pkg:task-writing:bodies before you write a body. It has the
type contracts, what each section owns, and the templates.
